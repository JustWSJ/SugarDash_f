## 2. 모양

- 버튼은 그림자 없는 납작한 둥근 상자, 테두리 2px(실제 6px), 모서리 16(실제 48). 창은 모서리 24(실제 72).
- 실제 크기는 1080×1920 기준. 시안은 1/3(360×640)로 그렸다.
- 글꼴은 주아. 로고 156, 제목 63~78, 버튼 48~72, 본문 39~45.
- 버튼 글자는 가운데 정렬에 `Align By Geometry`를 켠다(글꼴 위아래 여백과 상관없이 글자 모양으로 가운데에 맞춘다).

## 3. 화면별

- 타이틀: 방 그림 배경과 고양이, 왼쪽 위 레벨 표시, 오른쪽 위 톱니 설정 버튼, 위쪽 로고와 유형 띠, 아래쪽 `시작`.
- 유형 선택: 방 그림 배경, 숫자 원이 있는 1형·2형 카드, 아래 `나중에 설정에서 바꿀 수 있어요` 띠.
- 설정: 어두워진 타이틀 위의 흰 창(타이틀이 뒤에 비친다). 1형·2형은 한 줄, 그 아래 인트로 다시보기·튜토리얼 다시하기·돌아가기. 버튼 높이·글자 크기가 모두 같고 사이 간격도 같다. 지금 유형 버튼은 분홍, 위에 `지금` 띠.
- 컷툰: 화살표·건너뛰기 버튼은 다른 화면 기본 버튼과 같은 흰 둥근 상자, 진회색 글자.
- 결과: 점수 카드, 요약, 경험치 묶음, 버튼 두 개. 경험치 글은 묶음 상자 가운데(왼쪽 레벨 원만큼 오른쪽도 비움)([result-screen.md](result-screen.md)).
- 탈락 장면 말풍선: 다른 화면 기본 버튼과 같은 흰 둥근 상자, 진회색 주아 54, 가운데 정렬. 어른을 가리키는 꼬리는 아직 없다.
- 혈당 재기 습관 말풍선(1형): 탈락 말풍선과 같은 모양. 아래쪽 가운데, 측정기 원 위에 겹치지 않게 둔다.
- 주행: 위쪽에 혈당만큼 차는 혈당바(채움 색이 혈당에 따라 초록·노랑·빨강으로 바뀜)와 그 오른쪽 일시정지 아이콘, 아래 가운데 혈당 숫자, 오른쪽 점수. 오른쪽 아래 흰 원 측정기(1형). 카운트다운은 흰 원 안 숫자, 상태 글은 그 아래 띠.
- 선택 패널: 아래쪽 흰 창. 맨 위 남은 시간 막대(분홍, 연습 모드와 결과 문구 창에서는 숨김), 제목, 2단계 간식은 그림 자리가 있는 2칸 카드, 나머지 선택지는 넓은 버튼, 맨 아래 `어른에게 알리기`. 간식 카드와 넓은 버튼은 각 묶음 안에서 순서를 섞는다.

## 4. 그림 파일

- `Assets/_Project/Art/UI/Sprites/`: 둥근 상자(`RoundBox`, `RoundBoxLight`, `RoundFill`, `RoundBorder`), 원(`CircleBorder`, `CircleFill`), 방 그림(`RoomTitle`, `RoomTypeSelect`), 고양이(`CatTitle`), 아이콘(톱니, 일시정지, 측정기, 왕관, 반짝이).
- 방 그림·고양이·아이콘은 시안 그림을 옮긴 임시 그림이다. 같은 이름의 파일로 바꾸면 화면에 그대로 들어간다.
- 간식 카드의 그림 자리는 비어 있다(선택지 그림 작업).
