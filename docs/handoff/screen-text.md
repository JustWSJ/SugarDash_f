# 화면 문구 한눈에 보기

- 범위: 게임 화면에 나오는 모든 글자. 화면 순서대로 모았다.
- 상태: **확정**은 코드에 `// 확정`이 붙은 줄이다. 나머지는 모두 **초안**이다. 확정은 맡은 팀원이 정한다.
- 고치는 법: "파일" 칸의 문구 파일에서 따옴표 안의 글자를 바꾼다. 확정한 줄에는 `// 확정`을 붙인다.
- 지킬 것: 치료·진단을 주장하지 않는다. 음식을 "나쁜" 것으로 부르지 않는다. 아이를 탓하지 않는다. "죽음", "생존"을 쓰지 않는다. 테스트가 금지 낱말(나쁜, 죽, 생존, 치료)을 확인한다.
- 말투: 안내와 버튼은 존댓말(-요)이다. 어른이 하는 말(탈락 말풍선, 습관 말풍선)은 반말이다.
- `{ }` 안은 게임이 채우는 값이다.

## 6. 고른 뒤 문구 (`AnswerFeedbackText`)

선택 뒤 약 1초 동안 패널 제목 자리에 보인다. 무엇을 골랐는지만 말하고 정답·오답은 말하지 않는다.

| 고른 것 | 문구 | 상태 |
| --- | --- | --- |
| 2단계 간식 | {간식}을/를 골랐어요 | 초안 |
| 3단계 양 | {간식}을/를 조금·알맞게·많이 마셨어요(주스·탄산음료) / 먹었어요(크래커·사과) | 초안 |
| 측정기 | 측정했어요 | 초안 |
| 계속 달리기 | 계속 달리기를 골랐어요 | 초안 |
| 먹을 게 없어요 | 먹을 게 없다고 했어요 | 초안 |
| 다시 재기 | 다시 쟀어요 | 초안 |
| 다시 달리기 | 다시 달리기를 골랐어요 | 초안 |
| 주스 마시기(2형) | 주스를 마셨어요 | 초안 |
| 어른에게 알리기 | 어른에게 알렸어요 | 초안 |
| 시간 초과 | 시간이 다 됐어요 | 초안 |
